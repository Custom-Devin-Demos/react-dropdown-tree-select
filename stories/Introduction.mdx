# react-dropdown-tree-select

A lightweight and fast select component for hierarchical tree data, with tags (pills), search, partial selection and
keyboard navigation. Written in TypeScript, built with hooks and `StrictMode` safe on React 18
(React `^16.8 || ^17 || ^18`).

```bash
npm i react-dropdown-tree-select
```

```tsx
import DropdownTreeSelect, { TreeNode } from 'react-dropdown-tree-select'
import 'react-dropdown-tree-select/styles.css'

const onChange = (currentNode: TreeNode, selectedNodes: TreeNode[]) => console.log(currentNode, selectedNodes)

export const App = () => <DropdownTreeSelect data={data} onChange={onChange} />
```
